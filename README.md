# MTC LOG — сайт без Framer

Обычный статический сайт: HTML + CSS + немного JS. Ни сборки, ни зависимостей.

## Структура

```
index.html            главная (видео-фон на весь экран)
menu/index.html       меню
about/index.html      About
services/index.html   Services
team/index.html       Team
contact/index.html    Contact
404.html              страница «не найдено»
robots.txt, sitemap.xml   для поисковиков
_headers              правила кэша (Netlify, Cloudflare Pages)
vercel.json           то же для Vercel
assets/
  style.css           все стили (адаптив: телефон / планшет / десктоп)
  main.js             переключение пунктов на About / Services / Team
  hero-*.av1.mp4      фон главной, AV1 (лёгкий, современные браузеры)
  hero-*.mp4          то же в H.264 — запасной вариант для старых браузеров
  hero-*.webp         первый кадр (показывается, пока грузится видео)
  hero-og.jpg         картинка для превью ссылки в мессенджерах/соцсетях
  logo.svg, favicon-*.svg, apple-touch-icon.png, uncut-sans-book.woff2
```

## Фон главной

Сделан из оригинальной GIF (222.gif, 238 МБ), замедлен в 1.5 раза (3 сек вместо 2)
с досчётом промежуточных кадров до 30 fps, и «отдалён» на 15%: кадр уменьшен, а края
дорисованы размытым продолжением картинки с мягкой виньеткой — знак в центре выглядит меньше.
Команды сборки с отдалением — в истории проекта (ffmpeg: maskedmerge + gblur + vignette).

| Экран                                  | Видео (AV1 / H.264)   | Первый кадр |
|----------------------------------------|-----------------------|-------------|
| Телефон, планшет вертикально           | 0.3 МБ / 0.42 МБ      | 49 КБ       |
| Ноутбук, планшет горизонтально (≤1366) | 0.2 МБ / 0.92 МБ      | 32 КБ       |
| Большие экраны                         | 0.66 МБ / 2.4 МБ      | 94 КБ       |

Как открывается главная: сразу виден размытый кадр (он вшит прямо в `index.html`),
через долю секунды он становится чётким, а затем плавно запускается видео.
Пользователи с включённым «уменьшением движения» в системе видят только кадр.

Пересобрать видео с другой скоростью (поменять `1.5*PTS`: больше — медленнее, меньше — быстрее):

```
ffmpeg -i 222.gif -vf "scale=1920:-2:flags=lanczos,setpts=1.5*PTS,framerate=fps=30:interp_start=0:interp_end=255:scene=100" -c:v ffv1 -pix_fmt yuv420p m1920.mkv
ffmpeg -i m1920.mkv -c:v libsvtav1 -preset 5 -crf 42 -g 120 -pix_fmt yuv420p -movflags +faststart -an assets/hero-1920.av1.mp4
ffmpeg -i m1920.mkv -c:v libx264 -preset slow -crf 28 -tune grain -g 120 -pix_fmt yuv420p -movflags +faststart -an assets/hero-1920.mp4
```

(1280: `scale=1280:-2`; телефон: `scale=-2:1072,crop=720:1072`, AV1 `-crf 44`, H.264 `-crf 31`.)
После замены файлов поднимите номер `?v=` у style.css / main.js во всех HTML и у видео в index.html.

## Скорость (замер на медленном мобильном интернете 1.6 Мбит/с, задержка 150 мс)

| Экран        | Размытое превью | Чёткий кадр | Видео играет |
|--------------|-----------------|-------------|--------------|
| Телефон      | 0.46 с          | 1.2 с       | 1.5 с        |
| Ноутбук      | 0.44 с          | 1.0 с       | 1.2 с        |
| Монитор 1920 | 0.44 с          | 2.1 с       | 2.5 с        |

Внутренние страницы: первое отображение ≈ 0.5 с, фото команды на телефоне ≈ 0.45 с.
На обычном 4G / Wi-Fi — в несколько раз быстрее; при повторном заходе всё берётся из кэша.

Кэш уже настроен в `_headers` (Netlify, Cloudflare Pages) и `vercel.json` (Vercel):
страницы всегда свежие, файлы из `assets/` хранятся у посетителя 30 дней.
Если заменяете картинку/видео — поднимите ей `?v=` в HTML (или переименуйте файл).

## Запустить у себя

```
python -m http.server 8090
```

и открыть http://localhost:8090

## Выложить

Подходит любой статический хостинг: Netlify, Vercel, Cloudflare Pages, GitHub Pages
или свой сервер. Просто загрузить содержимое этой папки в корень сайта.
Пути к файлам начинаются с `/`, поэтому сайт должен открываться с корня домена
(например `https://www.mtclog.eu/`).

Адреса страниц — `/about/`, `/services/` и т.д. Старые адреса Framer без слэша (`/about`)
хостинги сами перенаправляют на версию со слэшем, ссылки не сломаются.
Если домен будет другим — замените `https://www.mtclog.eu` в `<head>` страниц,
`robots.txt` и `sitemap.xml`.
